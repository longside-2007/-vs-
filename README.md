# Hollow Knight VS Hornet - C++ SFML 动作对战游戏

## 📖 项目简介
这是我的《高级语言程序设计》大作业。本项目是一个基于 C++ 和 SFML 图形库开发的双人同屏 2D 动作对战游戏。
作为《空洞骑士》的粉丝，我尝试在代码中还原了小骑士（Knight）和大黄蜂（Hornet）的经典招式和打击感，包括物理重力、受击反馈、逐帧动画以及技能冷却系统。

## 🎮 游戏特性
- **双人同屏竞技**：两名玩家在同一台电脑上分别控制两个角色进行对决。
- **经典招式还原**：
  - **小骑士**：平砍、受击位移、标志性的“空中下劈弹跳”。
  - **大黄蜂**：地面高速冲刺、滞空“丝线风暴”大招、原版语音（Heigali! Adido!）。
- **手写物理引擎**：
  - 基础重力模拟与地板碰撞检测。
  - AABB 矩形碰撞判定（平砍）与圆形欧几里得距离判定（丝线大招）。
- **视听体验**：采用多层背景渲染、动态镜头跟随、以及 SFML 音频混合。

## ⌨️ 操作说明
### 1P - 小骑士 (Knight)
- **移动**：`A` / `D`
- **跳跃**：`W`
- **普通攻击**：`J`
- **下劈**：空中时按 `S` + `J`

### 2P - 大黄蜂 (Hornet)
- **移动**：`←` / `→`
- **跳跃**：`↑`
- **地面冲刺**：`Numpad 0`
- **丝线风暴**：空中时按 `Numpad 1`

- **通用**：游戏结束后按 `R` 键重启。

## 🛠️ 技术实现
- **编程语言**：C++
- **图形库**：SFML 2.5.1+
- **架构设计**：采用面向对象编程（OOP）。
  - **BaseCharacter**：虚基类，处理重力、移动和基础物理。
  - **状态机**：使用 `int status` 管理角色的待机、跑动、攻击等动画状态。
  - **动画系统**：利用 `std::vector<sf::Texture>` 存储序列帧，通过计时器控制播放速度。

## 📁 目录结构说明
- `Hornet/`, `Knight/`: 存放角色的动作序列帧图片。
- `*.wav`, `*.mp3`: 游戏音效与背景音乐。
- `background.png`: 场景地图背景。
- `arial.ttf`: 游戏 UI 字体。
- `BaseCharacter.h / .cpp`: 角色父类。
- `Knight.h`, `Hornet.h`: 角色实现。
- `main.cpp`: 游戏核心逻辑、事件循环与渲染。

## 🚀 如何运行
1. 安装 **Visual Studio** 并在项目中配置好 **SFML** 环境。
2. 确保 `sfml-graphics.lib`, `sfml-window.lib`, `sfml-system.lib`, `sfml-audio.lib` 已添加到附加依赖项。
3. 将资源文件（图片、声音、字体）放在生成目录（`.exe` 所在文件夹）下。
4. 编译运行即可。
